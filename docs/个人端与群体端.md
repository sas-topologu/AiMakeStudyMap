# 智点星谱 · 个人端与群体端

> **术语基准**：见 [`docs/概念模型.md`](概念模型.md) —— 全项目只有 **个人端**（属于一个人的全功能学习工具）与 **群体端**（一群人共用的知识库 + 社区）两种东西。
> 那个文件讲**为什么这么分**；本文讲**怎么摆、怎么跑**。

> **定位**：一个**工具** —— 独立使用即全功能；群体端是**可选**的「数据仓库 + 社区」。

## 一、两个部件（同仓库两个目录）

| 目录 | 部件 | 是什么 |
|---|---|---|
| `server/` | **服务内核** | 数据与社区服务：知识库、账号、学习进度、投稿/审核、讨论/二创、举报。跑在个人机器上、只服务一个人 → 属于**个人端**；跑在公网、服务一群人 → 就是**群体端**。 |
| `web/` | **个人端界面** | 界面工具：星图、知识卡、闯关、管理。可指向任意数据源。 |
| `content/` | 知识卡内容 | 知识卡 JSON 与制卡/校验工具。 |

- **独立使用（全功能）**：本机同时跑「服务内核 + 个人端界面」，全部功能可用（无需联网）。
- **群体端**：把服务内核部署到服务器（如 `https://aimakestudymap.online`），作为**仓库**（最新知识库）与**社区**（多人）。

## 二、三种运行方式

### 1. 独立使用（推荐个人使用）
```bash
npm install
npm run build          # 构建个人端界面
npm run import         # 知识库入库（仓库里有多少卡就导入多少）
npm start              # 启动服务内核（默认 3000）
```
浏览器打开 `http://localhost:3000` → **独立使用**：社区类功能自动不可用。

### 2. 连上群体端（作为数据仓库 + 社区）
把服务内核部署到服务器（见 `docs/上线部署指南.md`），个人端通过域名访问 → **已连群体端**：社区功能可用。

### 3. 个人端指向其它数据源
个人端「设置 → 数据源」里可填写并切换到别的数据源地址（记住历史），切换后重新加载。
- 默认指向**本机库**（当前页面地址 / 构建时注入的 `VITE_TERMINAL_URL`）
- 独立使用时无法使用社区/分享功能（那些依赖群体端多人环境）

## 三、管理员（两级）

| 级别 | 怎么来 | 能做什么 |
|---|---|---|
| **库管理员**（owner） | **在本机登录后认领**（设置 → 认领为库管理员）；仅本机请求可认领 | 完全权限：设置/轮换**授权密钥**、管理库、审核、投稿、举报 |
| **二级管理员** | 持有 owner 发放的**授权密钥**，登录后提交（注册页或登录后）| 审核投稿/勘误/举报、管理面板；**不能**设置授权密钥、不能管库 |
| 普通用户 | 直接注册 | 学习、闯关、发帖、投稿（经审核） |

- owner 在「设置 → 管理员」里**生成授权密钥**，发给他人 → 对方即成为二级管理员。
- 部署在公网时，owner 可在服务器上对本机发起认领（`POST /api/auth/claim-owner`，仅 loopback 允许）。

## 四、知识库来源（都可选，不强制）

工具**不依赖内置知识库**，空库也能正常使用。补充知识卡的三种方式：
1. **AI 制作**：走 `/api/agent/spec`（规范+模板）→ `/api/agent/cards` 投稿 → 审核通过入库。
2. **自有 JSON**：放进 `content/cards/`，运行 `npm run import`。
3. **从群体端拉取**（可选）：
   ```bash
   npm run pull-cards -- https://aimakestudymap.online
   npm run import
   ```

## 五、数据与安全

- 库文件：`server/data/starmap.db`（SQLite），**不入版本库**。
- 个人端与库的通信：HTTP(S) API；公网群体端配 HTTPS 证书 → 个人端连它时可校验身份（防仿冒）。
- 群体端**不主动读取**用户内容；仅在用户显式触发（投稿/举报/@AI）时经任务桥处理。
- 密钥：`STARMAP_SECRET`（鉴权签名）、`STARMAP_ADMIN_KEY`（引导密钥，可选）。

## 六、可关闭模块

「设置 → 功能模块」可关闭：导航 / 社区 / AI 助手 / 分享星图 / 计时 / 流星 / 星光粒子。
- 独立使用时，**社区**、**分享星图**自动不可用（与开关联动）。

## 七、风险防护

### 1. 数据源可能不在（离线容错）
- **熔断**：请求失败即进入**离线态**，在冷却期（30 秒）内**快速失败、不再发起网络请求**，避免反复申请空转占用资源；冷却后自动尝试恢复一次。
- **本地兜底**：离线时星图/知识卡使用浏览器本地缓存（`starmap.cache.v2`）继续渲染；初始中心退化为缓存的任一节点。工具本身不依赖数据源在线。
- **提示**：顶部出现「数据源暂时不可达」提示条，可点「立即重试」手动恢复。
- 个人端内**没有**对数据源的轮询（计时器只在本地倒数），不会持续占用网络与 CPU。

### 2. 域名丢失 / 被他人夺走（防仿冒）
- 每个库有**持久化的身份指纹**（首次运行生成，存于数据库；`GET /api/terminal/info` 返回）。
- 个人端**首次连接时记住该指纹**（TOFU）；之后若指纹不同 → 说明"不是原来的库"（例如域名被他人接管、换了一台服务器），顶部出现**红色警示**并暂停自动信任，需用户明确确认或切回默认数据源。
- 注意：**HTTPS 证书不足以防这种替换**（新域名持有者也能申请合法证书），因此需要指纹校验。

### 3. 信息通道：**上行（上传）与下行（下载）都受限，且格式可配置**

**下行（库 → 个人端，下载通道）**
- **界面外壳**：只允许界面运行所需格式（`html/js/css/json/svg/png/jpg/gif/webp/ico/字体/txt/webmanifest`）；
  其他扩展名（如 `.exe`、`.zip`）一律 `404` —— 站点**不会被当作任意文件分发通道**。
- **用户内容**（图片/附件）：`/api/assets/*` 按**可配置白名单**放行，带防目录穿越。
- 所有响应带 `X-Content-Type-Options: nosniff`（防止浏览器按内容嗅探类型、把文件当可执行内容）；SVG 另附 CSP 禁脚本。

**上行（个人端 → 库，上传通道）**
- 接口只接受 `application/json`（其余返回 `415`）；**文件以 base64 放进 JSON** 传输，通道保持统一。
- `POST /api/upload`（需登录）限 5MB，落盘 `content/assets/uploads/`，返回站内 URL；评论区可「🖼 插入图片」。

**格式白名单可配置（不写死）**
- 库管理员在「设置 → 管理员 → 允许的文件格式」维护（逗号分隔）。
- 默认：`png / jpg / jpeg / gif / webp / svg / pdf / txt / md / csv / json`。
- 说明：用户内容的白名单**可配置**；界面外壳的格式是构建产物、固定为安全集合。

> ⚠️ 诚实说明：如果个人端界面是**由库的页面提供**的，那么"域名被夺"者也能替换界面代码——此时任何前端校验都可能被绕过。
> 真正的防护是**从可信来源获取个人端**：本机运行（独立使用）或从 GitHub 安装；再用指纹校验库身份。这也是"工具（独立使用即全功能）"的定位价值。

### 4. 身份指纹与去中心化数据分布**互不影响**
- 指纹只是"库的身份证"，用于个人端判断"是不是我信任的那台库"；**知识卡是纯 JSON、不带库绑定**，可自由在库之间传递（`pull-cards`）。
- 个人端按**每个数据源地址分别记住指纹**，指向任意数据源互不干扰。

## 八、库不再对外提供学习界面（改造）

**群体端只提供：数据接口 + 管理界面。**

| 访问者 | 访问 `/`（首页） | 说明 |
|---|---|---|
| **本机**（如 PC 个人端内置的库） | 正常提供学习界面 | 用于独立使用全功能 |
| **公网**（经域名/代理访问） | 仅显示「库说明页」，学习界面路由返回 404 | 群体端不再支持网页学习 |
| 任何人 | `/admin` → **库管理界面**（登录后操作） | 管理界面 |

- **管理界面**（`server/public/admin/`，纯静态、无构建）：登录、库概览（版本/指纹/授权密钥状态）、待处理任务（人工通过/驳回）、投稿队列、举报、**二创审核**（通过/拒绝）、**勘误处置**（采纳/驳回 + 备注）、**学习策略**、授权密钥与允许文件格式（仅库管理员）。
- **管理只在库里**：个人端界面**没有**管理页（旧的 `/admin`、`/manage` 两个页面已下线）；管理员从个人端图标「🛡 库管理」在新标签打开所在库的 `/admin`。
- 手机/PC 个人端不受影响：个人端界面**内置在 App 里**；PC 个人端因内置本机库（`127.0.0.1`）仍可正常加载学习界面。
- 部署后：浏览器打开 `https://你的域名` 会看到说明页；管理请访问 `https://你的域名/admin`。

## 九、学习策略（约束可调、可关）

计时/防沉迷、跃迁额度这类**约束**不是库的规矩，而是本库自己的设置（`/api/terminal/policy`，仅库管理员可改）：

| 策略 | 默认 | 关闭后 |
|---|---|---|
| 计时与防沉迷 | 开（当日上限 120 分钟） | 不设上限；计时器仍可用，但闯关不再要求先开计时 |
| 跃迁额度 | 开（月赠 1 · 上限 2） | 跃迁直接开放，不扣额度、也无门槛 |

- 个人端会按策略**隐藏或显示**对应入口 —— 关掉约束**不会减少任何学习功能**，只是不再卡人。
- 单机形态下这些约束由你自己决定；群体端也**不替个人端设限**，只提供仓库与社区。

## 十、成果与认证（社区展示）

个人端离线也能完成学习，所以群体端**无法验证离线发生的事**。处理方式（详见 `docs/概念模型.md` §4）：

| 状态 | 怎么产生 | 例子 | 显示 |
|---|---|---|---|
| **已认证** ✔ | 必须联网，由群体端当场见证 | **点亮** | 带「已认证」标记 |
| 未认证 | 个人端本地完成（含断网） | **通关** | **不做任何标记** |

- **只标好的，不标差的** —— 没有"低可信 / 未验证 / 存疑"这类说法和标记。
- 未认证的成果**照常展示、照常可用**，与他人完全平等：不降权、不隐藏、不提示。
- 标记只出现在两个地方：**速通榜**与**拓荒者纪念碑**的「已认证」徽章；其余一切界面不做区分。
- 数据上只有一个字段 `user_node_state.certified`（1 = 库当场见证 / 0 = 离线完成、事后上传），写入时取 `MAX`：**只补不撤**。
- 只有需要"确实发生过"的**稀缺名额**（拓荒者 / 前十纪念碑、速通榜）才只认已认证的；其余场合一视同仁。
- 群体端**只标不拦**：不接受就不接收，接受了就照单收下，不删改、不回退，也不指责。
