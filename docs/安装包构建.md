# 智点星谱 · 安装包构建

## 一、PC 个人端（Windows / macOS / Linux）

**定位**：独立使用即全功能 —— 安装包内已含**本机库**（Express + SQLite + 500 张知识卡），装上就能用，无需联网、无需另装 Node。

### 方式 A：云端构建（推荐，不需要本机装任何工具）
1. 打开仓库 → **Actions** 标签 → 左侧选 **Build Desktop Installer**
2. 点右侧 **Run workflow** → 再点绿色 **Run workflow**
3. 等几分钟跑完 → 点进本次运行 → 底部 **Artifacts** 下载：
   - `zhidian-starmap-desktop-windows-latest` → `ZhidianStarmap-Setup-0.1.0.exe`（Windows 安装包）
   - `...-macos-latest` → `.dmg`
   - `...-ubuntu-latest` → `.AppImage`

### 方式 B：本机构建（需要本机已 `npm install`）
```bash
npm install            # 会下载 Electron（约 100MB+）
npm run build          # 构建前端
npm run desktop        # 开发方式运行（直接打开窗口）
npm run desktop:dist   # 打包，产物在 release/ 目录（Windows 出 .exe 安装包）
```
> Windows 打包首次可能需要 VS Build Tools（因为 better-sqlite3 是原生模块，需要为 Electron 重编译）。
> 遇到问题就用**方式 A**（云端构建机环境齐全）。

### 数据位置
桌面版把数据库与上传文件放在**用户目录**（打包后的程序目录只读），首次启动会自动把随包知识卡导入数据库：
- Windows：`%APPDATA%\智点星谱\starmap.db`
- macOS：`~/Library/Application Support/智点星谱/starmap.db`
- Linux：`~/.config/智点星谱/starmap.db`

## 二、手机个人端（Android APK）

**定位**：只做界面 —— 指向某个**数据源**（你的群体端或本机库）。手机上没有 Node 运行时，因此不内置库。

### 构建（用 GitHub 云端，本机不需要 Java/Android SDK）
1. 仓库 → **Actions** → 选 **Build Android APK** → **Run workflow**
2. 可填「个人端默认指向的数据源地址」（留空则用仓库变量 `TERMINAL_URL`，再留空则默认 `https://aimakestudymap.online`）
3. 跑完 → 本次运行页面底部 **Artifacts** 下载 `zhidian-starmap-apk`（内含 `app-debug.apk`）
4. 把 APK 传到手机安装（需允许"安装未知来源应用"）

> 更省事：在仓库 **Settings → Secrets and variables → Actions → Variables** 新建变量 `TERMINAL_URL` = `https://你的数据源`，之后每次构建都默认指向它。

### 说明
- 当前产出的是 **debug 签名** APK，适合自己安装测试。要正式发布（上架/长期分发），需生成 **release keystore** 并配置签名——需要时我再补一段签名配置。
- 手机端只做界面，可在 App 内「设置 → 数据源」切换指向的数据源（默认已注入你指定的地址）。

## 三、两者与"个人端 / 群体端"架构的关系

| 形态 | 是否内置本机库 | 默认指向 | 独立可用 |
|---|---|---|---|
| **PC 个人端** | ✅ 内置（装完即全功能） | 本机库（`127.0.0.1`） | ✅ 完全离线可用 |
| **手机个人端** | ❌ 无 | 构建时注入的数据源地址 | 需能访问该数据源（离线时用本地缓存降级） |
