# 智点星谱 · 客户端与终端

> **定位**：一个**工具** —— 单机即可全功能；云端是**可选**的「数据仓库 + 社区」。

## 一、两个部件（同仓库两个目录）

| 目录 | 部件 | 是什么 |
|---|---|---|
| `server/` | **终端** | 数据与社区服务：知识库、账号、学习进度、投稿/审核、讨论/二创、举报。装在哪台机器，哪台就是"终端"。 |
| `web/` | **客户端** | 界面工具：星图、知识卡、闯关、管理。可指向任意终端。 |
| `content/` | 知识卡内容 | 知识卡 JSON 与制卡/校验工具。 |

- **单机全功能**：本机同时跑「终端 + 客户端」，全部功能可用（无需联网）。
- **云端**：把终端部署到服务器（如 `https://aimakestudymap.online`），作为**数据仓库**（最新知识库）与**社区**（多人）。

## 二、三种运行方式

### 1. 单机（推荐个人使用）
```bash
npm install
npm run build          # 构建客户端
npm run import         # 知识库入库（仓库里有多少卡就导入多少）
npm start              # 启动终端（默认 3000）
```
浏览器打开 `http://localhost:3000` → **单机模式**：社区类功能自动不可用。

### 2. 云端（作为数据仓库 + 社区）
部署到服务器（见 `docs/上线部署指南.md`），客户端通过域名访问 → **云端模式**：社区功能可用。

### 3. 客户端指向其它终端
客户端「设置 → 终端」里可填写并切换到别的终端地址（记住历史），切换后重新加载。
- 默认指向**本地终端**（当前页面地址 / 构建时注入的 `VITE_TERMINAL_URL`）
- 单机模式下无法使用社区/分享功能（那些依赖云端多人环境）

## 三、管理员（两级）

| 级别 | 怎么来 | 能做什么 |
|---|---|---|
| **终端管理员**（owner） | **在终端本机登录后认领**（设置 → 认领为终端管理员）；仅本机请求可认领 | 完全权限：设置/轮换**授权密钥**、管理终端、审核、投稿、举报 |
| **二级管理员** | 持有 owner 发放的**授权密钥**，登录后提交（注册页或登录后）| 审核投稿/勘误/举报、管理面板；**不能**设置授权密钥、不能管终端 |
| 普通用户 | 直接注册 | 学习、闯关、发帖、投稿（经审核） |

- owner 在「设置 → 管理员」里**生成授权密钥**，发给他人 → 对方即成为二级管理员。
- 云端部署时，owner 可在服务器上对本机发起认领（`POST /api/auth/claim-owner`，仅 loopback 允许）。

## 四、知识库来源（都可选，不强制）

工具**不依赖内置知识库**，空库也能正常使用。补充知识卡的三种方式：
1. **AI 制作**：走 `/api/agent/spec`（规范+模板）→ `/api/agent/cards` 投稿 → 审核通过入库。
2. **自有 JSON**：放进 `content/cards/`，运行 `npm run import`。
3. **从云端终端拉取**（可选）：
   ```bash
   npm run pull-cards -- https://aimakestudymap.online
   npm run import
   ```

## 五、数据与安全

- 终端数据库：`server/data/starmap.db`（SQLite），**不入版本库**。
- 客户端与终端的通信：HTTP(S) API；云端终端配 HTTPS 证书 → 客户端连它时可校验身份（防仿冒）。
- 服务端**不主动读取**用户内容；仅在用户显式触发（投稿/举报/@AI）时经任务桥处理。
- 密钥：`STARMAP_SECRET`（鉴权签名）、`STARMAP_ADMIN_KEY`（终端引导密钥，可选）。

## 六、可关闭模块

「设置 → 功能模块」可关闭：导航 / 社区 / AI 助手 / 分享星图 / 计时 / 流星 / 星光粒子。
- 单机模式下，**社区**、**分享星图**自动不可用（与开关联动）。
