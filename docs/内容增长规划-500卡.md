# 智点星谱 · 500 卡课程地图（v1）

> 2026-08 制定。目标：**重制现有 75 张 + 新增 425 张 = 至少 500 张**；其中**前沿领域卡 ≥30 张（★）**；其余新增**优先供给「通往 ★ 前沿卡」的路径**；多出的自选主题。
> 制作标准：《知识卡制作规范》v2.1（推演式制作最高原则）。全部新卡先入 `content/staging/` 校验，再移入 `content/cards/` 入库。
> 策略：每张基础卡一节课，沿「动机问题 → 推演 → 结论 → 应用」制作；前沿卡可引用论文，未定论处 `credibility=disputed`。
